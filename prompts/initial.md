## **Подсказки во время поиска вакансий**

Для получения подсказок по поисковым фразам в API hh.ru предусмотрен метод `GET /suggests/vacancy_search_keyword`.

Он помогает дополнять вводимый пользователем текст названиями должностей, компаний и другими часто используемыми поисковыми фразами. Полученные подсказки предназначены для дальнейшего использования в параметре `text` метода поиска вакансий `GET /vacancies`.

### **Параметры запроса**

- `text` — обязательный параметр. Текст для поиска подсказок, длина — от 2 до 3000 символов.
- `host` — домен сайта, к которому идёт обращение
- `locale` — необязательный параметр. Идентификатор локали.
- `HH-User-Agent` — обязательный заголовок с названием приложения и контактной почтой разработчика.

### **Пример успешного ответа**

Для запроса с текстом `Java` API может вернуть следующий ответ:

```
{

}
```
