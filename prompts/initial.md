Пример ответа на запрос «подсказки во время поиска вакансий».

Краткий ответ: для подсказок при поиске вакансий предусмотрен метод
`GET /suggests/vacancy_search_keyword`. Он дополняет вводимый текст названиями должностей,
компаний и другими частыми поисковыми фразами. Полученные подсказки можно использовать в
параметре `text` метода `GET /vacancies`.

Параметры запроса: `text` — обязательный текст для поиска подсказок длиной от 2 до 3000
символов. `host` — домен сайта, к которому идёт обращение. `locale` — необязательный
идентификатор локали. `HH-User-Agent` — обязательный заголовок с названием приложения и
контактной почтой разработчика.

Пример успешного ответа: для запроса с текстом `Java` API может вернуть объект с полем
`items`, массивом подсказок и полем `suggest_id`. Пример JSON находится во вложении.

Пример ошибки: при некорректном параметре `locale` API может вернуть ошибку `400 Bad
Request` с полями `request_id`, `bad_argument`, `bad_arguments`, `description` и
`errors`. Пример JSON находится во вложении.
