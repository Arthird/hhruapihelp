# Скрипт - подготовка документации

Для того, чтобы LLM, общающаяся с пользователем, могла отвечать полно и достоверно, ей необходимо предоставить информацию в подходящем виде.

## Принцип работы

Скрипт `index.js` осуществляет пребразование `.yml` файлов в `input/` `.md` в `output/` (markdown), преждевременно удаляя все файлы из `output`

## Подготовка к запуску

```bash
npm install
chmod +x convert.sh
```

## Запуск

```bash
./convert.sh
```
